概览

适用版本：单门店 V1 · 更新日期：2026-09-17 · 来源：飞书数据口径说明与当前交互原型

一、需求背景及目标

需求背景

当前首页经营数据主要存在“口径混用”和“关键指标缺口”两类问题。

问题 1：“业绩”的分类口径不平行

  • 员工端若将“今日业绩”拆成现金、卡付、团购和签单，容易混淆“员工完成了多少服务”和“门店今天通过什么方式完成交易”两个不同问题。
  • 员工业绩应按照提成逻辑拆分为劳动业绩、售卡业绩和产品业绩；现金、卡付、团购记账和经理签单属于消费方式，更适合店主查看。
  • 经理签单需要单独明确回款与提成规则。未回款签单应标记“待回款”，并透明展示是否计入提成及具体计提时间，减少员工提成争议。

问题 2：店主端缺少资金、客户和人效三条经营观察线

  • 资金健康：业绩不等于实际到账资金。卡业绩属于预收，签单属于应收，卡付是历史预收的消耗；仅看业绩无法判断门店现金是否健康，需要同时关注今日实收、耗卡金额、预收卡负债余额和签单未回款。
  • 客户经营：缺少到店人次、新客数、客单价和退款等指标，仅有项目排行只能说明“卖了什么”，无法判断客流和客户质量。
  • 人员效率：缺少店主视角的员工业绩排行，无法直观看到员工产出和门店人效。

需求目标

  • 建立店主首页、店员首页、数据总览和营收分析四个页面之间清晰、连续的经营数据查看路径。
  • 统一跨页面重复字段、日期维度和趋势图的展示与交互规则，减少理解与研发实现偏差。
  • 帮助店主快速掌握门店收款、营业额、消费结构及异常情况，帮助店员查看个人业绩与预计提成。

二、全局规则

  • 统计区间统一采用“开始时间 ≤ 统计时间 < 结束时间”，日报按自然日、周报按自然周、月报按自然月统计。
  • 金额字段按“分”存储与返回，页面统一换算为“元”并保留两位小数；数量字段展示整数，占比保留一位小数。
  • 正向业务按完成或支付成功时间计入；退款按退款成功时间计入当前周期，不回写原业务所在周期。
  • 取消、失败和已作废的数据不计入有效统计；无有效分母时占比展示“—”，不以 0% 代替。
  • 跨页面重复出现的同名字段共用同一套字段定义、计算公式、时间归属和计入范围。

三、本期范围

页面本期展示范围
店主首页收款、门店业绩、我的业绩及趋势；收款数字区域与箭头可进入门店经营报表。
店员首页个人业绩、业绩构成、预计提成及趋势。
数据总览核心数据与趋势、交易看板、办卡充值、销售排行。
营收分析营业额与收款趋势、消费构成、消费方式、退款与异常。

报表日期维度本期支持日报、周报和月报；“员工业绩分析”“卡相关”“客流分析”仅保留栏目入口，暂不开放页面。

首页经营数据口径说明

适用版本：单门店 V1 · 更新日期：2026-09-15 · 来源：飞书数据口径说明

一、角色与权限

角色首页可见数据业务目的
店主收款合计、门店业绩、我的业绩掌握现金流入及门店产出
店员我的业绩、预计提成了解个人产出及收入预估

二、数据口径说明

统一规则：统计区间采用“开始时间 ≤ 统计时间 < 结束时间”；所有金额字段数据库按分存储、接口按分返回，前端转换为元并保留两位小数。

页面：首页－收款卡片

收款合计
字段基本信息建议字段编码：gross_receipt_amount
数据类型：金额；默认值：0.00；统计维度：门店、统计周期
业务定义统计周期内门店实际收到的资金扣除实际退款后的净额，用于反映门店资金净流入，不等同于销售收入或员工业绩。允许出现负数，例如当期没有新增收款但发生历史订单退款。
计算公式收款合计 = 开单实收 + 办卡/充值 − 订单退款
时间归属规则开单实收和办卡/充值按支付成功时间计入；订单退款按退款成功时间扣减，不回写原订单所在周期。
计入范围只统计实际资金流入与流出。卡付、团购记账和经理签单不产生当期实际资金流入，不计入收款合计。
开单实收
字段基本信息字段编码：order_actual_receipt_amount
数据类型：金额；默认值：0；统计维度：门店、统计周期
业务定义统计周期内，门店通过项目消费或产品购买订单实际收到的资金。只统计实际资金支付部分，不统计卡付、团购、经理签单等非当期资金流入，为退款前金额。
计算公式开单实收 = Σ 消费订单支付明细中的实际资金支付金额
混合支付时，只汇总现金、微信、支付宝、银行卡和信用卡对应的支付明细金额。
时间归属规则支付状态为支付成功时，按支付成功时间计入。后续退款不冲减原开单实收，在退款成功周期计入订单退款。
计入范围计入项目消费、产品购买中的现金、微信、支付宝、银行卡和信用卡支付；不计入储值卡或次卡卡付、团购记账、经理签单、办卡充值、支付失败、取消或已作废支付流水。
办卡/充值
字段基本信息字段编码：card_actual_receipt_amount
数据类型：金额；默认值：0；统计维度：门店、统计周期
业务定义统计周期内，顾客买卡、续卡、充值、续次或卡升降级时门店实际收到的资金，属于预收款，不代表顾客已经完成消费。赠送储值金额和赠送次数不计入。
计算公式办卡/充值 = Σ 卡业务支付明细中的实际资金支付金额
时间归属规则支付状态为支付成功且卡业务生效时，按支付成功时间计入。后续退款通过订单退款字段在退款成功周期扣减。
计入范围计入买卡、续卡、充值、续次和卡升降级中的现金、微信、支付宝、银行卡和信用卡支付；不计入赠送金额或次数、已有卡余额支付、团购记账、经理签单及未支付或已作废业务。
订单退款
字段基本信息字段编码：order_refund_amount
数据类型：金额；默认值：0；页面始终按正数展示；统计维度：门店、统计周期
业务定义统计周期内，门店通过退款操作实际退回给顾客的资金金额。
计算公式订单退款 = Σ 退款成功流水中的实际资金退款金额
部分退款按本次实际退回资金统计；同一退款不得因关联多个原支付明细而重复累计。
时间归属规则按退款成功时间归属统计周期，不按照原订单创建、支付或完成时间统计，不回写历史收款数据。
计入范围计入消费订单和卡业务中，通过现金、微信、支付宝、银行卡或信用卡实际退回的资金；不计入退回卡余额、恢复次卡次数、取消团购记账、撤销经理签单，以及失败或已取消退款。

页面：首页－业绩卡片

总业绩
字段基本信息字段编码：total_performance_amount
数据类型：金额；默认值：0；允许为负数；统计维度：门店、员工个人、统计周期
业务定义统计对象在统计周期内产生并归属到其名下的有效业绩金额，用于衡量业务产出，不等于收款合计或营业额。
计算公式总业绩 = 劳动业绩 + 售卡业绩 + 产品业绩
员工总业绩汇总当前员工三类业绩流水；门店总业绩汇总当前门店全部有效业绩流水。
时间归属规则各分类业绩分别按照其正向业务生效时间和退款冲减时间归属，总业绩不另设独立时间字段。
计入范围只汇总三类有效业绩流水。同一业务明细多人协作时，全部员工分配金额之和必须等于该明细可计业绩金额，禁止重复累计整笔订单。
劳动业绩
字段基本信息字段编码：labor_performance_amount
数据类型：金额；存储单位：分；展示单位：元；统计维度：门店、员工、统计周期
业务定义员工为客户完成项目服务后产生，并按服务归属或业绩分配规则归属到统计对象名下的有效业绩。衡量服务产出，与支付方式无关。
计算公式劳动业绩 = Σ 订单明细可计劳动业绩金额 − Σ 项目退款冲减金额
时间归属规则订单已完成且支付状态有效时，按订单完成时间生成正向业绩；项目退款或撤销成功时，按退款或撤销成功时间生成负向业绩。部分退款仅冲减对应项目金额，并沿用原订单员工归属快照。
计入范围不计入产品销售、买卡、续卡、充值、挂单、已取消或已作废订单，以及未设置业绩金额的赠送项目。
产品业绩
字段基本信息字段编码：product_performance_amount
数据类型：金额；存储单位：分；展示单位：元；统计维度：门店、员工、统计周期
业务定义员工销售门店实物产品后产生，并按销售归属或业绩分配规则归属到统计对象名下的有效业绩。支付方式不影响产品业绩分类。
计算公式产品业绩 = Σ 订单明细可计产品销售业绩金额 − Σ 产品退款冲减金额
时间归属规则产品订单已完成且支付状态有效时，按订单完成时间生成正向业绩；退款成功时按退款成功时间生成负向业绩。部分退货仅冲减对应产品明细金额，并沿用原订单员工归属快照。
计入范围不计入项目服务、买卡、续卡、充值、赠品、未完成订单、已取消或已作废订单。
售卡业绩
字段基本信息字段编码：card_performance_amount
数据类型：金额；存储单位：分；展示单位：元；统计维度：门店、员工、统计周期
业务定义员工通过买卡、续卡或充值业务获得，并按售卡归属规则归属到统计对象名下的有效业绩。属于员工绩效指标，不属于客户消费金额，也不等同于会计收入。
计算公式售卡业绩 = Σ 卡业务可计售卡业绩金额 − Σ 退卡或充值退款冲减金额
可计业绩金额取客户实际支付本金，不包含赠送储值金额和赠送次数。
时间归属规则买卡、续卡或充值支付成功且业务生效时生成正向业绩；退卡、充值退款或业务撤销成功时生成负向业绩。部分退款按实际退回本金冲减，并沿用原业务员工归属快照。
计入范围计入支付成功的买卡、续卡、充值、升降级、续次；不计入赠送金额或次数、已有卡的消费卡付、未支付、取消或已作废业务，以及项目服务和产品销售。
业绩构成
字段基本信息字段编码：performance_composition
数据类型：复合字段；组成：劳动业绩、售卡业绩、产品业绩及其构成比例
业务定义用于说明总业绩分别由劳动、售卡和产品三类业务贡献了多少，分类金额必须与总业绩使用完全相同的统计对象和时间范围。
计算公式分类占比 = 分类业绩金额 ÷ 总业绩 × 100%
仅当总业绩大于 0 且三项分类金额均不小于 0 时计算。展示比例四舍五入，三项之和通过尾差修正保持为 100%。
特殊状态总业绩等于 0，或任一分类金额小于 0 时，不计算占比、不展示构成条，只展示三项金额；接口占比字段统一返回 null，不得使用 0 冒充有效占比。
预计提成
字段基本信息建议字段编码：estimated_commission_amount
数据类型：金额；默认值：0；允许因退款冲减出现负数；统计维度：门店、员工个人、统计周期
业务定义根据统计对象的有效业绩和业务发生时生效的员工提成方案计算出的预估提成，不代表最终已结算或已发放金额。
计算公式预计提成 = Σ 单条有效业绩金额 × 该业绩命中的提成规则 − Σ 退款对应提成冲减
时间归属规则正向提成跟随对应业绩生效时间计入；退款冲减跟随退款业绩流水生效时间计入；使用业务发生时保存的提成规则快照，不用当前最新方案重算历史数据。
计入范围计入命中有效提成规则的劳动、售卡和产品业绩；不计入未配置规则、明确不计提成、未生效或已作废业绩；门店预计提成为全部员工预计提成之和。

三、隐私规则

店主进入首页时，收款卡片金额默认隐藏，可点击收款卡片的小眼睛显示或隐藏；店员进入首页时，“我的业绩”卡片金额默认隐藏，可点击卡片小眼睛显示或隐藏。店主的业绩卡片数据直接展示。

页面逻辑说明

说明内容随中间页面同步切换，包含页面展示与交互逻辑，以及对应字段编码、计算公式、时间归属和关键统计边界。

店主首页逻辑说明

内容来源：《门店经营报表数据口径说明｜首页数据》。店主首页同时展示门店资金流入与业绩产出，两类数据保持独立表达。

一、交互

一、收款卡片
  • 卡片展示收款合计、开单实收、办卡/充值、订单退款及当前周期的对比结果；退款金额按正数展示，收款合计允许出现负数。
  • 点击“今日 / 本周 / 本月”切换展示周期，卡片内金额和对比文案整体刷新。
  • 进入首页时金额及对比结果默认隐藏；点击标题旁的小眼睛显示，再次点击恢复隐藏。
  • 仅点击收款合计的大金额区域或右侧“›”进入「门店经营报表－营收分析」；日期标签、说明图标和卡片空白区域不触发跳转。
  • 点击标题旁的信息图标打开整张收款卡片的数据口径说明弹窗；点击关闭按钮或遮罩关闭。
二、业绩卡片
  • 点击“门店业绩 / 我的业绩”切换统计对象；点击“今日 / 本周 / 本月”切换展示周期。
  • 卡片展示总业绩、预计提成，以及劳动业绩、售卡业绩、产品业绩三项构成；三类业绩按业务类型展示，不按现金、卡付、团购或签单等支付方式拆分。
  • 正常状态展示三色构成条及三项金额；总业绩为 0、总业绩为负或任一构成项为负时，隐藏构成条，只保留三项金额。
  • 预计提成作为预估结果与总业绩并列展示；出现退款冲减时允许显示负数。
  • 店主首页的业绩数据直接展示，不提供隐藏按钮；点击标题旁的信息图标打开业绩字段说明弹窗。
三、状态与其他入口
  • 金额字段无数据时展示 ¥0.00；正常业务金额、退款冲减及负值均保留正负号，不以空白代替。
  • 快捷功能以独立入口展示，点击后进入对应业务功能；本原型不展开快捷功能的后续页面。
  • 右侧“页面状态演示”仅用于查看隐藏、正常、业绩为 0 和业绩为负四种状态，不改变实际导航。

二、数据口径说明

店员首页逻辑说明

内容来源：《门店经营报表数据口径说明｜首页数据》。店员首页只展示当前登录员工的“我的业绩”，不展示门店收款和门店整体业绩。

一、交互

一、页面展示
  • 页面不提供“门店业绩 / 我的业绩”范围切换，统计对象始终为当前登录员工。
  • 卡片展示总业绩、预计提成，以及劳动业绩、售卡业绩、产品业绩三项构成；支付方式不作为员工端的业绩分类。
  • 点击“今日 / 本周 / 本月”切换展示周期，卡片内全部数据同步刷新。
  • 预计提成为预估结果；正向业绩和退款冲减均可影响页面显示，金额允许为负。
二、隐藏与特殊状态
  • 进入页面时，总业绩、预计提成、三项构成金额及构成条默认隐藏。
  • 点击标题旁的小眼睛显示全部业绩数据，再次点击恢复隐藏；切换周期不会改变当前隐藏状态。
  • 仅当总业绩大于 0 且三项构成均不为负时展示构成条；总业绩为 0、为负或任一构成项为负时只展示三项金额。
三、字段说明弹窗

点击标题旁的信息图标打开业绩卡片的数据口径说明弹窗，集中查看总业绩、预计提成和三项业绩构成的解释；点击关闭按钮或遮罩关闭。

二、数据口径说明

数据总览页面逻辑说明

内容来源：《门店经营报表数据口径说明｜数据总览与营收分析》。本页只展示当前门店；顶部仅“数据总览”和“营收分析”可进入，其余栏目保持不可用。

一、交互

一、日期筛选与全局刷新
  • 点击“日报 / 周报 / 月报”只切换周期类型，不直接打开日期面板；日报对应自然日，周报对应自然周，月报对应自然月。
  • 点击右侧日期区域打开底部选择面板：日报选择年月日，周报选择年份、月份和月内周次，月报选择年月；周报面板实时显示具体起止日期。
  • 点击“确定”后，核心数据、趋势、交易看板、办卡充值和销售排行使用同一周期整体刷新；点击“取消”、遮罩或关闭按钮放弃修改。
二、核心数据与趋势
  • 核心数据展示开单实收、办卡/充值、订单退款、客单价、成交客户和新增客户；金额和人数无数据时展示 0，客单价无法计算时展示“—”。
  • 点击任一指标后，该指标进入选中状态，下方趋势标题、折线、坐标轴和悬浮数据同步切换。
  • 日报横轴展示选中日期及此前 6 天，共 7 个点；周报展示选中周及此前 7 周，共 8 个点；月报展示选中月份及此前 11 个月，共 12 个点。
  • 纵轴根据当前序列的最小值、最大值及数据类型自适应；出现负值时保留负值区间和零轴。
  • 点击横轴区域吸附至最近数据点并显示日期、指标名称和数值；键盘支持左右方向键、Home 和 End 切换数据点。
三、交易看板
  • 交易看板暂时只保留“消费方式 / 消费构成”两个观察维度，两者展示同一营业额总额，只是拆分角度不同。
  • 消费方式展示开单实收、团购记账、卡付、经理签单；消费构成展示项目消费、产品消费。
  • 点击切换标签后，圆环图、中心合计、分类金额和占比同步刷新；合计为 0 时占比展示“—”。
四、办卡充值
  • 模块展示合计金额、办理总笔数、卡类型构成条，以及储值卡、套餐卡、计次卡、折扣卡明细。
  • 储值卡和套餐卡在主金额下方分别展示本金与赠金；赠金作为补充信息展示，不与本金合并为实收金额。
  • 每个卡类型同时展示金额、笔数和占比；合计为 0 时占比展示“—”。
五、销售排行
  • 类型标签可切换服务、产品和卡项；排序控件可切换销售额和销售数量，数量单位分别为次、件、张。
  • 销售额包含团购记账、实际支付、销售签单（页面中的经理签单）和卡付金额；销售额与销售数量均不计入已退款、已作废订单。
  • 切换任一条件后，标题合计、总笔数、名次、数值及单位同步刷新。
  • 默认展示前 5 项；存在更多数据时显示“查看全部”，点击展开完整列表，再次点击收起。
六、数据口径说明弹窗

核心数据、交易看板、办卡充值和销售排行标题右侧均提供信息图标；点击打开对应模块的字段说明弹窗，点击关闭按钮、遮罩或按 Esc 关闭，关闭后焦点返回原入口。

二、数据口径说明

营收分析页面逻辑说明

内容来源：《门店经营报表数据口径说明｜数据总览与营收分析》。页面在同一统计周期内展示营业额、实际收款、消费内容、结算方式及退款异常。

一、交互

一、导航与日期
  • 点击顶部“数据总览”切回总览页面；“员工业绩分析 / 卡相关 / 客流分析”保持不可用，点击不切换内容。
  • 点击左上角返回按钮回到店主首页。
  • 日报、周报、月报和右侧日期区域的操作方式与数据总览一致；确认新日期后，本页全部模块同步刷新。
二、核心数据与双趋势
  • 首张卡片并列展示营业额、收款合计及各自的周期对比；两项均允许出现负数，对比期为 0 或无法比较时展示“—”。
  • 下方两条不同颜色的折线分别对应营业额和收款合计；日报展示近 7 日，周报展示近 8 周，月报展示近 12 个月。
  • 两条折线共用纵轴，纵轴读取两组序列的联合最小值和最大值后自适应；出现负值时必须显示零轴并保留负值区间。
  • 切换周期或日期后，两项汇总值、对比文案、折线、横轴标签、纵轴刻度和范围文案同步更新。
三、消费构成
  • 卡片顶部展示退款前营业额，圆环中心展示扣除退款后的营业额。
  • 圆环按项目消费、产品消费分段；右侧分别展示金额和占比，颜色与圆环分段一致。
  • 两项明细之和与营业额保持一致；营业额为 0 时占比展示“—”。
四、消费方式
  • 构成条展示开单实收、团购记账、卡付、经理签单四个大类；四类金额之和与营业额保持一致。
  • 每个大类名称在左，金额和占比在右；子分类缩进展示且金额使用常规字重。
  • 开单实收下方直接展开微信、支付宝、银行卡、信用卡、现金；支付方式为动态列表，后续新增方式时同步增加。
  • 团购记账下方直接展开抖音、美团、大众点评、口碑和其他平台；团购平台为动态列表，页面只展示记账金额，不展示或推断平台结算金额。
  • 退款影响对应大类及其子分类的展示金额；合计为 0 时占比展示“—”。
五、退款与异常
  • 订单退款展示金额、退款笔数和退款率；经理签单展示金额、签单笔数和签单占比。
  • 点击“订单退款”整行跳转至「订单流水－退款」Tab；本原型不绘制目标页面，点击后以轻提示说明跳转目标。
  • 经理签单当前仅展示汇总数据，不提供跳转；当比例无有效分母时展示“—”。
六、数据口径说明弹窗

核心数据、消费构成、消费方式、退款与异常标题右侧均提供信息图标；点击打开对应模块的字段说明弹窗，点击关闭按钮、遮罩或按 Esc 关闭。
